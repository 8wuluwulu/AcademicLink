# Анализ проекта AcademicLink (20.05.2026)

## 1. Текущее состояние
Проект представляет собой CRM для репетиторов на стеке FastAPI + Aiogram 3 + SQLModel. 
Система готова к многопользовательской работе (multi-tenant).

### Что сделано сегодня:
- **Исправлен баг слотов:** Теперь время работы берется из базы данных (`availability_slots`), а не из конфига.
- **Предотвращены накладки:** Запись невозможна, если время занято уроком в статусе `PENDING` или `CONFIRMED`.
- **Проверка таймзон:** Внедрена строгая проверка UTC/MSK.
- **Добавлен Roadmap:** Создан план развития коммерческой версии.

## 2. Коммерческий потенциал
Целевая аудитория: репетиторы 25-45 лет.
Главная ценность: экономия времени на записи и исключение «забытых» уроков.

### Ключевые фичи для продажи (MVP+):
1. **Мини-лендинг:** Личная ссылка репетитора для записи учеников.
2. **Управление слотами в боте:** Редактирование графика без программиста.
3. **Массовые рассылки:** Инструмент маркетинга для репетитора.
4. **Умные напоминания:** Снижение процента неявок.

## 3. Технический долг
- Необходимо внедрить миграции Alembic для новых полей (`lesson_duration`, `wants_reminders`).
- Нужно реализовать фронтенд часть (веб-интерфейс).
